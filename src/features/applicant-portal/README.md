# Applicant Portal Module (Reserved — Phase 2)

This directory is reserved for Phase 2 implementation of the GTSInfo Candidate Recruitment Platform per SRS v1.2 Sections 4 through 9.

### Planned Features:
- Applicant Dashboard
- Profile Management (Contact, Education, Technical Skills, Experience, Portfolio Links)
- Resume & Certificate Management (PDF/JPG Uploads with 5MB limit via Multer)
- Job Application Submission & Reference Tracking (`APP-YYYY-XXXXX`)
- Application Status Tracking (Submitted, Under Review, Shortlisted, Interview Scheduled, Selected, Rejected, Withdrawn)
- Interview Schedule & Instructions View
- My Offers & Branded PDF Offer Letter Downloads
- Account Settings & Password Management
